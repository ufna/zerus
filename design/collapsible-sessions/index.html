Свёрнутая колонка сессий

Развёрнутая колонка — текущий сайдбар без изменений. Свёрнутая полоса собрана из тех же строк и элементов и работает сама по себе: клик выбирает сессию, наведение показывает подсказку. Кнопка «⇥» в полосе разворачивает колонку: полоса растёт вширь, каждая строка остаётся на своей высоте, бейджи статуса и провайдера переезжают на свои места. Ползунок позволяет рассмотреть переход покадрово. Раскрытие при наведении — опция в настройках приложения (шестерёнка внизу рейки → Sessions), по умолчанию выключена.

Свёрнутая полоса

  • Те же строки той же высоты: группа 40 px, карточка 94 px. Порядок, скролл и выделение общие с развёрнутой колонкой.
  • Карточка: рамка выделения, кромка attention / unread / error, бейдж статуса без текста (те же цвета и значки), инициалы, иконка провайдера — как в узкой карточке сейчас.
  • Непрочитанный ответ поверх работы или вопроса — точка на бейдже; при раскрытии она вырастает в обычный бейдж-конверт.
  • Группа: та же цветная плашка и один главный счётчик: ! → ● новые → ● работают → всего. У свёрнутой группы он показывает скрытые сессии.
  • Поиск — квадрат с лупой, из фильтров виден только активный чип, внизу — число сессий.

Без раскрытия при наведении

  • Полоса остаётся узкой. Клик по плитке выбирает сессию, клик по плашке сворачивает или разворачивает группу.
  • Через 250 мс наведения на плитку появляется подсказка: название, статус, последнее действие, папка и машина. На плашке — счётчики группы.
  • «Свернуть» — новая кнопка в шапке рядом с «⋯»; в полосе та же кнопка разворачивает колонку. Переход — морфинг на месте: строки не прыгают, статус и провайдер переезжают, текст проявляется.
  • Клик по лупе раскрывает панель поверх контента и ставит фокус в поиск. Закрывается по Esc или клику мимо панели, булавка закрепляет колонку.
  • Пока курсор над полосой, справа появляется тонкая ручка прокрутки; без курсора её нет.
  • Раскрытие при наведении — опция Settings → Sessions → Expand the collapsed session list on hover, по умолчанию выключена. Включённая: через 150 мс полоса растёт поверх контента и сворачивается через 350 мс после ухода курсора.

Как это ляжет на Qt

  • Тот же SessionList и SessionDelegate: делегат получает свойство прогресса 0…1 и интерполирует позиции так же, как прототип.
  • В свёрнутом режиме в сплиттере остаётся слот 64 px; при наведении панель поднимается над detail (raise()) и растёт через QVariantAnimation.
  • Закрепление возвращает панель в сплиттер; свёрнутость хранится в QSettings рядом с workspace/compact.
  • Опция — ещё один флажок в списке раздела Sessions в SettingsPage.h: ключ workspace/expandSessionsOnHover, по умолчанию false.
